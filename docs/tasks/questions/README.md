# Questions

Задания, выполнение которых невозможно продолжить без дополнительной
информации или решения пользователя: противоречивые требования, критическая
неоднозначность, выбор между вариантами реализации.

Если задание попало сюда, агент:

1. фиксирует в файле задания, какой информации не хватает и почему она нужна;
2. формулирует конкретные вопросы и, если полезно, варианты ответа;
3. переносит файл в эту директорию и прекращает работу над заданием.

Формат дополнения в файле задания:

```markdown
## Дополнительные вопросы

### Вопрос 1. Краткая формулировка

Сам вопрос.

Варианты:

- Вариант A.
- Вариант B.
```

## Возобновление работы

Пользователь сам отвечает на вопросы прямо в файле, переносит его обратно в
`docs/tasks/` и запускает агента снова. Агент читает файл целиком: исходные
требования, прошлые отчёты, вопросы и ответы, — и продолжает работу с учётом
ответов. Предыдущие отчёты не удаляются, новый этап дописывается в конец.

Общая система и правила статусов — в [`../README.md`](../README.md).
