# Done

Выполненные задания.

Сюда агент переносит файл задания только при одновременном выполнении условий:

- реализация соответствует исходным требованиям;
- новые тесты пройдены, существующие обязательные тесты не сломаны;
- все обязательные проверки (тесты, типы, линтер, сборка) завершились успешно
  или применимы к заданию и выполнены;
- критерии приёмки из файла задания выполнены;
- в файл задания дописан отчёт о выполненных действиях и результатах проверок.

Самостоятельное утверждение агента об успехе основанием не считается:
непроведённая проверка не равна пройденной.

Файлы отсюда не удаляются и не переписываются: отчёт уже внутри и служит
историей. Если задание нужно переделать, пользователь сам возвращает файл в
`docs/tasks/`. Общая система и правила статусов — в
[`../README.md`](../README.md).
