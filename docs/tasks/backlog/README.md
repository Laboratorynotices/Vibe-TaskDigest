# Backlog

Очередь заданий на будущее: они уже сформулированы, но в работу не переданы.

- Задания создаёт и кладёт сюда пользователь.
- Агент **не** ищет и **не** выбирает задания в этой директории и не начинает
  их выполнение по собственной инициативе: очередь и приоритеты — решение
  пользователя.
- Чтобы задание попало в работу, пользователь сам переносит файл в
  `docs/tasks/`.

Имя файла — `ID-short-task-name.md` (`ID` — четыре цифры, нумерация общая для
всех статусов), один файл — одно задание. Общая система, жизненный цикл и
правила статусов — в [`../README.md`](../README.md).
