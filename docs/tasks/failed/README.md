# Failed

Задания, выполнение которых завершилось неудачно: реализация не доведена до
конца либо обязательные проверки (тесты, типы, линтер, сборка) завершились
ошибками.

Отчёт в файле задания обязан содержать:

- какие тесты провалились и какие проверки завершились ошибками;
- какие компоненты или функции перестали работать;
- какие изменения могли привести к проблемам;
- какие тесты и проверки прошли успешно;
- какие проблемы существовали до начала работы;
- что нужно исправить для успешного завершения.

Частично работающую функциональность нельзя выдавать за завершённую, поэтому
задание с падающими проверками остаётся здесь, а не в `done/`.

Повторное выполнение разрешено: пользователь исправляет требования или ставит
задачу на устранение проблем и сам переносит файл обратно в `docs/tasks/`.
Прошлые отчёты при этом сохраняются, новый этап дописывается ниже. Общая
система и правила статусов — в [`../README.md`](../README.md).
